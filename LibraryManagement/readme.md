Requirements
Before running the application, ensure you have the following:

Java Runtime Environment (JRE) - Version 22 or above:

Download and install from Oracle's official website.

MySQL Database OR XAMPP:

You need a MySQL server running on your machine.
Also create a database named libraryManagementSystem and import the libraryManagementSystem.sql file in the database.

MySQL JDBC Driver:

The project includes the MySQL JDBC driver (mysql-connector-java.jar) in the dist/lib folder.

Run the Jar file which is in dist folder with following command.

java -jar LibraryManagement.jar

Enter the credential of Database in the diaglog box. The project will run.
